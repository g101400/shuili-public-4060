# 水利工程一张图 — 项目说明

> 奥维采集数据 → 天地图一张图。支持浏览 / 筛选 / 增删改 / 多照片 / ovkmz 导入导出。
> 双形态交付：**PWA（浏览器/添加到主屏幕）** 与 **Android APK**。
> 当前版本：**v2.4.9**　|　作者 / 归属单位：**科技推广中心**

## 2. 如何运行（PWA）
```bash
cd shuili_app
python -m http.server 8770
# 浏览器打开 http://127.0.0.1:8770/
```
- 手机：Chrome 打开 → 右上角 ≡ → 「添加到主屏幕」，即成为 App。
- 离线：`data.js` 内嵌基础数据，断网仍可浏览/增删改。

---

## 3. 如何重新编译 APK
前提：已就绪的 Android 工具链（`C:/android_build/` 下 JDK17 + SDK34 + Gradle8.10）。
```bash
bash C:/android_build/ShuiLiApp/build_apk.sh
```
脚本会自动：① 同步 `shuili_app/`（排除 docs/中间文件）到 `assets/www`；② `assembleDebug` 编译；③ 取出 `shuili_app/ShuiLiApp-debug.apk`。
重编后**重装** APK 即可（升级安装需签名一致，debug 包覆盖安装即可）。

# 水利工程一张图 · 用户使用文档

> 版本：v2.5.0　|　归属：科技推广中心　|　更新：2026-09-12
> 适用对象：工程管理人员、巡查人员、需要查看水利工程（渠道 / 闸 / 坝 / 泵站 / 涵洞等）空间分布与参数的业务人员。

---

## 1. 这是什么

水利工程一张图，是把同事用**奥维互动地图**采集的工程坐标、照片与参数，统一展示在**天地图**底图上的一张可共享、跨端的工程图。支持手机与电脑查看，支持浏览、筛选、增删改、多照片、测距、周边搜索、定位与第三方导航，以及 ovkmz/kmz/csv 的导入导出。

- **数据来源**：奥维 `水利工程基础信息.ovkmz`（407 个基础建筑物）+ CSV 融合。
- **我的改动**：所有增 / 删 / 改都保存在本机（IndexedDB），离线可用，可随时备份或迁移。
- **双形态**：安卓 APK 安装包；桌面 / 手机浏览器直接打开（也可"添加到主屏幕"成为类 App 的 PWA）。

---

## 2. 快速入门（三步）

1. **打开应用**：安卓安装 `ShuiLiApp-debug.apk`；或在电脑浏览器打开网页版。
2. **看地图**：拖动、双指缩放查看蓝色水滴标记（每个标记即一个建筑物）；点击标记看详情与照片。
3. **找目标**：顶部输入框输入名称实时搜索；或点右上角 ☰ 菜单 → 筛选，多选管理所 / 建筑物类型。

做到这三步即可日常使用。以下为全部功能详解。

## 3. 安装与打开

### 3.1 安卓（推荐）
- 将 `ShuiLiApp-debug.apk` 传到手机并安装（首次需允许"未知来源"安装）。
- 首次打开建议授予 **定位** 与 **文件/存储** 权限，否则导航、导出/导入功能会受限。

### 3.2 桌面浏览器
- 用 Chrome / Edge 打开网页地址即可。
- 若部署为 PWA：菜单 → 添加到主屏幕，即可像 App 一样从桌面启动。

### 3.3 权限说明
| 权限 | 用途 | 不授予的影响 |
|------|------|--------------|
| 定位 | "定位我的位置"、导航起点 | 无法定位；安卓会自动引导去系统设置开启 |
| 文件/存储 | 导出/导入选择保存与读取位置 | 导出/导入无法选择目录（仅网页端走默认下载） |

## 5. 核心功能

### 5.1 浏览与搜索
- 拖动地图、双指缩放；点击蓝色水滴标记弹出详情（参数表 + 照片）。
- 顶部搜索框输入名称，实时按"名称 / 管理所 / 管理站 / 类型"过滤。

### 5.2 筛选
- 菜单 → 筛选：可**多选**建筑物类型（如 节制闸 / 跌水）与管理所（如 温泉所）。
- 选管理所后会**自动定位**到其范围中心；不选则显示全部。

### 5.3 添加 / 编辑 / 删除建筑物
- 菜单 → 添加：填写名称（必填）、类型、管理所、经纬度；可"在地图上点选坐标"或手填；可上传**多张照片**（正面 / 背面 / 侧面…）并填说明。
- 点开标记 → 编辑 / 删除。
- 所有修改进入"我的改动"，本机持久化。

### 5.4 底图（矢量 / 影像）
- 顶栏 🚫/🗺 按钮：**开关**天地图底图（默认关闭，仅显示点位，省流量；开启需联网）。
- 顶栏"矢量 / 影像"按钮 或 菜单 → 图源切换 / 底图开关：在**矢量地图**（道路注记清晰）与**影像地图**（卫星影像）间切换，弹窗会高亮当前选中项。

### 5.5 定位我的位置
- 菜单 → 定位我的位置：定位成功后地图上出现绿色"我的位置"点。
- **若 App 未授权定位**：安卓会自动跳转系统"定位设置"页；浏览器请手动在站点设置中允许定位。

### 5.6 导航（第三方软件）
- 点开建筑物 → 导航：优先以"我的位置"为起点，跳转**高德**等已安装的导航软件（坐标自动按 WGS84 转换）。
- 手机未装导航软件时，会唤起应用选择器；可选用浏览器打开地图链接。

### 5.7 测距
- 菜单 → 测距：依次点击地图或建筑物，自动绘制折线并显示**累计距离**（km/m 自适应）。
- 退出方式：点浮条"退出"、**再次点击菜单"测距"**、或按返回键 / Esc。
- "清除"可清空已添加的点重新测量。

### 5.8 周边搜索
- 菜单 → 周边搜索：选中心（我的位置 / 地图中心 / 某建筑物 / 地图点选）+ 半径（200–10000m），列出并高亮范围内的建筑物，并在地图画范围圈。
- "清除周边"可取消该筛选。

### 5.9 导入
- 菜单 → 导入：支持 **ovkmz / kmz / kml / csv**（奥维导出格式）。
- 安卓会弹出**系统文件夹选择器**（默认手机文档，可浏览任意目录、可多选），选中文件即导入；相同 ID 的记录会自动更新。
- v1.9.7 优化：导入解析时显示「正在解析导入文件，请稍后…」遮罩，避免误以为卡死；含照片的 kmz/ovkmz 照片不再丢失，与奥维 OKM 格式互通（双向可导入导出）。
- v1.99 修复：**ovkmz / kmz / zip / 7z 均可正常选择**（系统选择器不再按 MIME 过滤隐藏无映射扩展名）；导入完整识别奥维真实 ovkmz——照片（ovatta/ 附件）、参数（description 内「键 : 值」行）、管理所/管理站（Folder 层级自动映射）；导出的 ovkmz/kmz 采用奥维原生附件结构，本 APP 与奥维均可识别导入（往返一致）。

### 5.10 导出建筑物信息
- 菜单 → 导出：可**勾选指定建筑物**（默认全选当前范围），并选择格式：
  - **ovkmz / kmz**：含照片的 zip 包，可被奥维"导入"识别；
  - **kml**：通用矢量格式（不含照片）；
  - **csv**：属性表；
  - **潮河格式**：CSV 兼容（列：名称,管理所,管理站,类型,经度,纬度,说明），便于汇入业务系统。
- 导出位置：默认走**系统"保存位置"选择器**（可改路径/文件名，默认手机文档）；也可选"指定手机文件夹"，在真机授权后直接写入所选目录。
- v1.9.7：若在「筛选」中已选条件，导出范围默认选中「当前筛选」，一键导出筛选结果。
- v1.9.8：导出 **csv / 潮河格式** 时可在「导出列」中勾选要导出的字段（默认全选，至少选一列），详见 §5.23。

### 5.11 我的改动备份与迁移
- 菜单 → 导出/导入我的改动：把本机 IndexedDB 中的增删改导出为 JSON 备份，或导入他人的改动。
- 菜单 → 重置：清空"我的改动"，恢复 407 条基础数据（不影响设备端其他数据）。

### 5.12 关于
- 菜单 → 关于：显示版本、制作单位（科技推广中心），以及两个环境卡片：
  - **建议使用环境**：运行本应用所推荐的系统 / 浏览器 / 权限 / 屏幕配置。
  - **制作环境（本机运行环境）**：当前设备实际的操作系统、设备型号、运行环境、CPU、内存、GPU、屏幕。
- 菜单 → 帮助：内置功能速查。

### 5.13 获取经纬度
- 菜单 → 获取经纬度：一个弹窗同时支持三种取坐标方式：
  - **我的位置**：调用定位，自动填入当前经纬度的十进制数值（未授权则跳转系统定位设置）。
  - **地图点选**：关闭弹窗后在地图上点击任意点，坐标自动回填到弹窗。
  - **搜索建筑物**：输入名称实时过滤，点结果项即列出其坐标并飞到该点。
- 坐标格式为 **WGS84 十进制**（纬度, 经度），点「📋 复制」一键复制，便于粘贴到奥维 / 表格等。

### 5.14 列表快速定位 与 主菜单恢复
- **列表快速定位**：顶部 ☰ 打开建筑物列表，每项右侧有蓝色「快速定位 →」徽标，点一下即飞到该建筑物地图位置并自动收起列表（用户新增项显示「新增」）。
- **主菜单恢复（三击 / 浮动按钮）**：若打开列表或某个弹窗后一时找不到主菜单，可在**地图任意处快速连点三下**，先关闭卡住的弹窗/列表、再打开左侧主菜单；屏幕右下角还有一个常驻的圆形 **≡ 浮动按钮**，随时一点即开主菜单（顶部 ≡ 同样始终可用）。

### 5.15 批量导入照片
- 菜单 → 批量导入照片：先选来源——
  - **选择手机文件夹**：安卓弹出系统文件夹选择器，递归读取其中全部图片；
  - **选择压缩包(zip)**：读取 zip 内的全部图片；
  - **选择多个文件**：浏览器端直接多选。
- 导入后**按"照片文件名 → 建筑物名称"自动匹配**并保存：
  - 匹配键为文件名（去扩展名、小写、去空格/`_`/`-`/括号），且**忽略末尾数字**（如 `峰山口1.jpg`、`峰山口2.jpg` 均以 `峰山口` 参与匹配）。
  - 一张照片只匹配到**一个**建筑物时直接保存；匹配到**多个**建筑物（如 `峰山口` 同时匹配"峰山口测流桥"与"峰山口防洪闸"）会**弹窗让你勾选保存目标，可多选**，绝不会自动误存到错误的建筑物；完全无匹配的文件会弹窗列出，便于核对。
  - 若照片内容与已有照片**完全相同**（按内容指纹判定，而非文件名），会提示你**跳过 / 覆盖**，避免重复占用空间。

### 5.16 批量导入建筑物
- 菜单 → 批量导入建筑物：来源同上（文件夹 / zip / 多文件）。
- 支持 **csv / tsv / txt / kml / gpx / json / xlsx** 等多种表格/空间格式；xlsx 由原生端最佳努力转为 CSV 后解析。
- 导入后**按经纬度自动定位**；无经纬度时按名称定位。相同 ID 的记录会自动更新，不会重复。

### 5.17 导出照片
- 菜单 → 导出照片：选择范围（全部 / 当前筛选）与方式——
  - **压缩包(zip)**：把所有建筑物照片打包为 `建筑物照片.zip` 导出（推荐，跨端通用）；
  - **指定手机文件夹**：安卓弹出文件夹选择器，照片写入所选目录（需授予存储权限）。
- 导出规则：含多张照片的建筑物自动加**序号**（`建筑物名称_1.jpg` …）；结果**按管理所分文件夹**，每个管理所一个子目录（rel 路径 `管理所/建筑物名称_序号.扩展名`），方便按单位归集。
- v1.9.7 修复：彻底解决导出超过 30 张照片生成 0 字节压缩包的问题（原生分片增量解码），大批量照片导出稳定。

### 5.18 超大文件导入 / 导出（>3GB）
- kmz/ovkmz 因含大量照片可能超过 3GB，照片/zip 批量包同理。本版提供**超大文件模式**：
  - **断点续传**：导入过程中若中断（如退出/来电），再次进入时可**从检查点继续**，不必从头重来。
  - **流量提示**：当前**非 WiFi**（用流量）时，导入/导出大文件前会弹窗提醒"将消耗大量流量"，确认后才继续，避免误耗流量。
  - 适用：菜单「导入」的 kmz/ovkmz，以及「批量导入照片」「导出照片」的文件夹/zip 场景。

### 5.19 网盘导入导出（百度 / 夸克）
- 菜单 → 传输与共享 → **网盘导入导出**：可选**百度网盘**或**夸克网盘**，支持 kmz 与照片的导入 / 导出。
- 当前为接入脚手架：需在原生侧配置对应网盘的 **AppKey / Token** 后方可真实传输；未配置时 App 会提示你去配置，**不会静默失败**。

### 5.20 手机互传（服务端 / 客户端）
- 菜单 → 传输与共享 → **手机互传**：两台都装本 App 的手机，可一台开**服务端**、一台开**客户端**共享数据——
  - **服务端**：选一个 kmz/照片文件，App 起**局域网 HTTP 服务**（基于 `ServerSocket`），等待客户端来取；
  - **客户端**：填服务端手机显示的 `http://地址:端口/`，即可从服务端**下载 kmz 或照片**并导入。
- 前提：两台手机处于**同一 WiFi**；建议在真机环境下使用。

### 5.21 内容去重提示（按内容而非文件名）
- 导入 kmz 或照片时，App 会计算其**内容指纹（SHA-256，不支持时降级 CRC32）**。如果发现内容与**已导入过的源完全相同**（即使文件名不同），会弹窗提示你选择**覆盖**或**跳过**，避免重复导入、浪费空间。

### 5.22 分享建筑物 与 照片放大（v1.9.7）
- **分享建筑物**：打开任意建筑物详情，点「分享」按钮——App 将该建筑物的照片与信息（名称/管理所/管理站/类型/坐标/参数）打包成一个 zip，调用系统分享面板，可直接选 **微信 / QQ / 飞书** 等已安装应用发送（不支持系统分享时自动降级为下载该 zip）。
- **照片放大查看**：在灯箱（点开照片大图）中，**双击** 或 **双指捏合** 可放大，**单指拖拽** 平移，右下角「放大/还原」按钮一键切换；放大后点关闭自动复位，避免卡住。

### 5.23 导出表格可选列（v1.9.8，#39）
- 导出 **csv** 或 **潮河格式** 时，导出菜单内新增「**导出列**」多选区，列出该格式的全部可导出字段（csv：文件夹 / 名称 / 经度 / 纬度 / 说明；潮河格式：名称 / 管理所 / 管理站 / 建筑物类型 / 经度 / 纬度 / 说明）。
- 默认**全选**；至少需勾选**一列**，若一列都不勾会提示"请至少选择一列"并中止，避免导出空文件。
- 全选时导出的内容与旧版**逐字节一致**（向后兼容）；只勾部分列时，仅输出所选列（含表头）。
- 该能力在「水利 / 视频设备 / 古建」三套 APP 均按各自真实字段列提供，列名随领域词自动适配（如古建为 城市 / 区县 / 古建类型）。

### 5.24 导入文件选择与奥维 ovkmz 识别（v1.99 真机修复）
- **ovkmz / kmz / zip / 7z 选择**：v1.99 起导入（含照片 zip 批量导入）的文件选择不再按 MIME 隐藏文件——`.ovkmz`、`.7z` 等无标准 MIME 映射的扩展名也**正常可选**；选中后由 App 按扩展名识别（不支持的格式会明确提示）。
- **奥维 ovkmz 识别**：直接用同事从奥维导出的 `.ovkmz` 文件即可导入，自动识别：
  - 建筑物（名称 / 坐标 / 类型）；
  - **照片**（奥维 `ovatta/` 附件目录的照片按引用自动绑定到对应建筑物）；
  - **参数**（奥维 description 内「桩号：…｜设计流量：…｜闸槛高程：…」等键值行自动解析为建筑物参数）；
  - **管理所 / 管理站**（按奥维文件夹层级自动映射：上层文件夹为管理所，如"西田各庄所"，下层为管理段）。
- **导出兼容**：导出 ovkmz/kmz 采用奥维原生附件结构，导出的文件既可在**本 App** 再次导入（往返无损），也可被**奥维互动地图**导入识别。

### 5.25 添加建筑物（坐标优先两步式，v2.01）
- 菜单 → 添加，改为**两步向导**，确保坐标不漏填：
  - **第 1 步 · 获取坐标**：弹窗先引导你取坐标——「📍 我的位置」（自动定位填经纬度，未授权跳设置）、「🗺 地图点选」（关弹窗后在地图上点一下，坐标自动回填并进入下一步）、「🔍 搜索已有建筑物」（按名过滤取其坐标）、或「✍️ 手填经纬度」；若暂时不知道坐标，可点「稍后填坐标」跳过。
  - **第 2 步 · 填写信息**：坐标到位后进入表单，经纬度已**预填**（仍可点「📍 重新在地图上点选坐标」改选）；其余字段：名称（必填）、建筑物类型、管理所、管理站/渠道段、工程参数（多行 `字段: 值`）、照片（可多张）。填完保存即写入「我的改动」。
- 编辑既有建筑物仍沿用第 2 步表单并预填原值，不受影响。

## 6. 常见问题（FAQ）

**Q1：为什么有的建筑物点列表"定位"没反应？**
A：这些记录（多为 KMZ 导入所得）缺少有效坐标，已做保护——会提示"该建筑物缺少有效坐标，无法定位"，不会再静默失败。

**Q2：添加照片时"选择文件"点了没反应？**
A：安卓需在系统弹出的文件选择器中选图；若完全无反应，请确认已授予"文件/存储"权限并重启 App。

**Q3：底图不显示？**
A：底图需联网；请确认网络，并在顶栏点 🗫→🗺 开启底图。默认仅显示点位（省流量）。

**Q4：导出的 ovkmz 能被奥维识别吗？**
A：可以。ovkmz/kmz 为包含 doc.kml 与照片的 zip 包，奥维"导入"即可还原。

**Q5：弹窗关不掉、或找不到主菜单怎么办？**
A：关闭弹窗有三种方式——点右上角圆形 ×、点弹窗外灰色区域、按返回键 / Esc；列表栏与抽屉菜单也各自带关闭 ×。若打开列表或弹窗后一时找不到主菜单，在**地图任意处快速连点三下**，或点右下角圆形 ≡ 浮动按钮，即可强制收起并重新打开主菜单。

**Q6：批量导入照片/表格后没匹配上怎么办？**
A：照片按"文件名包含建筑物名称"匹配；若某张照片名与任何建筑物都不符，导入结束会弹窗列出未匹配的文件名，请据此重命名后重试。表格导入后按经纬度（无则按名称）定位，解析失败的文件也会在提示中说明。

**Q7：导入大文件时为什么会弹"将消耗大量流量"？**
A：当 App 检测到当前**未连接 WiFi**（在用蜂窝流量）且要导入/导出超过常规体积的 kmz/照片/zip 时，会先弹窗提醒，确认后才继续——这是超大文件模式的流量保护，避免误耗流量。已连 WiFi 时不会拦截。

**Q8：网盘导入导出为什么只提示"请配置"？**
A：网盘（百度/夸克）导入导出为接入脚手架，需在原生侧配置对应网盘的 AppKey/Token 后才会真实传输；未配置时仅提示你去配置，不会静默失败或发起空请求。配置方式由网盘提供方与实施方约定。

**Q9：手机互传连不上怎么办？**
A：手机互传依赖**同一 WiFi** 下的局域网 `ServerSocket` 服务。请确认两台手机连的是同一个 WiFi，且服务端已选好分享文件并处于"等待连接"状态；客户端填入服务端显示的 `http://地址:端口/`。该功能需真机实跑验证。

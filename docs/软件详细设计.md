## 1. 模块详细设计

### 1.1 store.js —— 本地存储
**职责**：管理用户改动的持久化（IndexedDB）与 UI 偏好（localStorage）。

**IndexedDB 封装**
- 库名 `shuili_app`，对象仓库 `kv`，键 `delta`。
- `get()`：读 delta，缺省返回 `{added:[],updated:{},deleted:[]}`。
- `set(delta)`：写入。
- `patch(fn)`：读 → 执行 `fn(d)` 修改 → 规范化（补全 added/updated/deleted）→ 写回。所有写操作经此。
- `clear()`：重置为空白 delta。
- `exportJSON()`：序列化 delta 为字符串（备份）。
- `importJSON(text)`：解析并校验（`added` 须为数组）后写入。

**UI 偏好**（localStorage key `ui_state`）
- `ui.get()/set()/clear()`：读写 `{office:[],btype:[],basemap:bool,layer:"vec"|"img",center:{lat,lng,zoom}}`；读写异常静默降级（不抛错、不阻塞）。

**关键约束**：基础数据只读；删除基础记录仅追加其 id 到 `deleted`，渲染时过滤，保证可重置恢复。

### 1.2 io.js —— 导入导出（零依赖）
**职责**：ZIP 读写、KML 构建/解析、ovkmz 导入导出、CSV 解析、照片 Base64。

**CRC32**：标准多项式 `0xEDB88320` 查表实现，`crc32(bytes)→uint32`。

**ZIP 写入 `zipStore(files)`**
- 仅 store（method=0）方式，逐文件写本地头(30B)+名+数据，并写中央目录(46B)+名、结尾(22B)。
- 头字段：版本20、flag0、method0、CRC、压缩/未压尺寸、名长。
- 多文件经 `concat(Uint8Array[])` 合并为单一 `Uint8Array`。

**ZIP 读取 `unzip(buf)`**
- 校验本地头签名 `0x04034b50`；逐条解析 method/compSize/nameLen/extraLen。
- method=0：直接取数据；method=8：经 `DecompressionStream("deflate-raw")` 解压。
- 按 `compSize` 偏移至下一条；空名/0尺寸防御退出。
- 环境不支持 deflate 时抛错提示改用 KML。

**KML 构建 `buildKML(records, root)`**
- 输出标准 KML：`Schema#shuili`（office/station/btype/type）、`SchemaData/SimpleData` 存字段、照片以 `<img src="files/xxx.jpg">` 入 description，并以 `<OvAttaItem FileName Url>` 标注（奥维兼容）。
- `recordToPlacemark(r)`：坐标 `lon,lat,0`；照片文件名 `{id}_{i}.jpg`。

**KMZ 字节 `recordsToKmzBytes(records)`**
- 组装 `doc.kml` + 各照片（从 `dataUrl` base64 解出字节）为 `{name,data}[]` → `zipStore`。

**解析 `parseKmlToRecords(kmlText)`**
- `DOMParser` 解析；遍历 Placemark：取 name/coordinates(name→lon,lat)/SimpleData(params，排除 office/station/btype/type/name)/description 中 `files/*.jpg` 文件名。
- id = `名称_经度5_纬度5`。

**导入 `importKmzBuffer(buf)`**
- `unzip` → 取 `*.kml` → `parseKmlToRecords` → 按 `photoFiles` 从 zip 取照片字节还原 `dataUrl`（`data:image/jpeg;base64,`）。

**CSV 解析 `parseCsvToRecords(text)`**
- 手写状态机（支持引号转义、换行、BOM）。
- 取 文件夹/名称/经度/纬度/Comment；`文件夹` 按 `/` 分段：`parts[1]=office`，`parts[2]=station--btype`（含`--`拆分）。
- Comment 多行 `字段:值` → params。

**导出入口**：`exportOvkmz/exportKmz/exportKml/exportCsv(records, root)`，文件名默认「水利工程基础信息」，CSV 带 BOM（`﻿`）以兼容 Excel。

**通用 CSV 构建 `buildCsv(records)`**（v1.6.0 从 `exportCsv` 抽出）
- 输出表头 `文件夹,名称,经度,纬度,Comment`；`文件夹 = office + "/" + station + "--" + btype` 还原层级；`Comment` 由 params 拼回 `字段:值`。供「导出建筑物信息 → 通用 CSV」与 JS 端直接调用。

**潮河格式 `buildChaohe(records)`**（v1.6.0）
- 输出表头 `名称,管理所,管理站,建筑物类型,经度,纬度,说明`；`说明` 由 params 以 `;` 连接（`字段=值;字段=值`）。
- 由菜单「导出」勾选「潮河格式（CSV 兼容）」时调用，文件名默认「潮河水利工程基础信息」。

**GPX 解析 `parseGpxToRecords(text)`**（v1.6.0）
- 正则提取 `wpt`/`rtept`/`trkpt` 的 `lat`/`lon` 与 `name`（`<name>`）；组装为 `{name,lon,lat}` 记录供批量导入建筑物。

**JSON 解析 `parseJsonToRecords(text)`**（v1.6.0）
- 解析 JSON 数组 `[{name,lon,lat,office?,station?,btype?,params?}, ...]`；缺字段容错为空白/0。

**工具**：`escapeXml`（防注入）、`b64ToBytes/bytesToB64`、`utf8/strFromUtf8`、`genId()`（`u_时间戳_随机`）、`csvOf=buildCsv`、`chaoheOf=buildChaohe`、`parseGpxToRecords`、`parseJsonToRecords`（v1.6.0 对外导出函数名）。

**内容指纹 `sha256Hex(bytes)`**（v1.8.0）
- 优先 `crypto.subtle.digest("SHA-256", bytes)` → 64 位十六进制；环境不支持时降级为 `"crc:"+crc32(bytes).toString(16)`。
- 对外经 `global.IO = {..., sha256Hex}` 暴露；`app.js` 的 `shaHexOfB64(b64)` 将 base64 转字节后调用，供导入去重与"已导入源"指纹比对。

### 1.3 app.js —— 业务逻辑（状态机）
**全局状态**
```
BASE[]         基础记录（来自 data）
DELTA           {added,updated,deleted}
records[]       渲染集 = BASE−deleted + updated + added
filter = {office:[], btype:[], q:""}
basemapOn       底图开关
layerType       "vec"|"img" 图源（矢量/影像）
imgLayer/ciaLayer  影像底图图层（img+cia）
lastCenter      上次地图中心
myLoc          定位坐标（供导航起点）
measurePts     测距顶点集合
nearbyCenter/nearbyRadius  周边搜索中心与半径
DEFAULT_CENTER = [40.30876,116.61107]   // 怀柔水库所质心
DEFAULT_ZOOM = 12
DIMS = {offices,stations,btypes}        // 由 records 动态去重排序
MARKER = L.divIcon(...)   // 倒立蓝色水滴标记（内联 SVG：尖端朝上、圆鼓覆盖点位、中心白点）
```

**启动流程**
1. `initMap()`：建 Leaflet 地图（默认中心/缩放），建 vec/cva 与 img/cia 四图层（暂不添加）、layerGroup 与 overlayGroup（测距/周边叠加层）。
2. `bindUI()`：绑定顶栏/抽屉/弹窗/列表/底图按钮/搜索/菜单事件。
3. `loadUI()`：读 UI 偏好；**无偏好则首次默认** `office=["怀柔水库所"]`、`basemapOn=false`、`center=null`。
4. `load()`：优先 `window.__DATA__`（APK/离线），否则 `fetch('data.json')`；`merge()` 合并 delta；`render()`。
5. 启动后：`addBasemap()`（按 basemapOn 决定加/不加底图）；若有 `lastCenter` 则 `setView`，否则 `fitToShown()`。

**`merge()`**：BASE 过滤 deleted → 应用 updated 覆盖 → 追加 added → `applyDims()`。

**`passFilter(r)`**（筛选核心）
```
if filter.office.length && !office.includes(r.office) → false
if filter.btype.length && !btype.includes(r.btype)   → false
if filter.q && 名称/office/station/btype 不含 q(小写) → false
if nearbyCenter && nearbyRadius!=null && haversine(nearbyCenter,{lat:r.lat,lon:r.lon})>nearbyRadius → false
return true
```
- 组内多选=并集；office 与 btype 之间=交集。

**`render()`**：清图层 → 遍历 records 经 `passFilter` 后建 marker（绑定 popup）→ 更新计数 → renderList。

**`fitToShown()`**：`layerGroup.getBounds().pad(0.12)` 自适应；空则回默认中心。

**筛选弹窗 `openFilter()`**
- 两组 chips（建筑物类型 / 管理所），点击切换 `.on` 并更新组内计数。
- 「应用」：读两组选中 → 写 `filter` → `render()`+`fitToShown()`+`saveUI()`。
- 「重置」：清空 `filter` 后重开弹窗。

**表单 `formHtml/openAdd/openEdit/saveForm`（v2.01 起：添加建筑物 = 坐标优先两步式）**
- `openAdd()` 不再直接弹表单，改为 `startAddStep1(null)`：第 1 步弹窗先引导获取坐标——① 我的位置（geolocation）② 地图点选（关闭弹窗后地图 click，经 `pendingCoordCb` 回调回填并进入下一步）③ 搜索已有建筑物（按名过滤取其坐标）④ 手填经纬度；支持「稍后填坐标」跳过（坐标为空仍可进第 2 步）。坐标到位后 `openAddForm(preset)` 进入第 2 步。
- 第 2 步表单 `formHtml(null, preset)`：字段名称(必填)、类型、管理所、管理站、经纬度(由 preset 预填，保留「📍 重新在地图上点选坐标」按钮可重选)、参数(多行)、照片(多张)。
- 点选坐标：开启 `pickMode`，地图 click 回填经纬度并 `togglePick(false)`；v2.01 支持 `pendingCoordCb` 向导式联动（点选后自动进入下一步而非仅回填）。
- `saveForm`：校验名称与非空经纬度 → 组装 Record（`custom:true`，base 依是否 editId）→ `Store.patch` 写入 added/updated → `merge()`+`render()`。

**`del(id)`**：确认 → patch 中从 added 移除或追加 deleted → merge+render。

**导入 `doImport(file)`**：按扩展名分流 kml/csv/kmz/ovkmz → patch 合并（存在则 updated，否则 added）→ 提示。

**导出 `exportMenu()`**：选范围(全部/筛选)+格式 → `IO.export*`。

**其它**：`stats`(分布计数)、`locate`(geolocation：成功标记「我的位置」；失败在 APK 经 `AndroidBridge.openLocationSettings()` 跳转系统定位设置，浏览器提示开启权限)、`navigate`(拼接高德 URI：`coordinate=wgs84` 自动转换，经 `AndroidBridge.openNav`/新标签跳转第三方导航)、`openNearby`/`nearCenter`(选中心+半径周边筛选并画范围圈)、`enterMeasure/exitMeasure/addMeasurePt`(测距：`haversine` 累计距离；菜单"测距"再次点击可退出)、`setLayer`(矢量/影像切换)、`openBasemap`(弹窗选择 矢量/影像/仅点位 并高亮选中)、`syncExport/Import`(delta JSON 备份)、`reset`(清 delta)、`help/about`、`openPhoto`(灯箱)。

**弹窗与退出 `openModal/closeModal/back`**
- `openModal(title,body,foot)`：置标题/内容/底部按钮，给 `#modal` 加 `.open`，并给新增的 `#modalMask` 遮罩加 `.show`（点击遮罩即 `closeModal`）。
- `closeModal()`：同时移除 `#modal` 与 `#modalMask` 的显示态。
- `back()`：**逐级关闭浮层**，供安卓物理返回键与浏览器 Esc 调用——优先级：弹窗打开→关闭弹窗；否则抽屉打开→关闭抽屉；否则测距中→`exitMeasure`；否则列表打开→收起列表；均不匹配返回 `false`（交还系统）。
- 全局 `window.APP.back` 暴露给原生 `onBackPressed`。

**关于页 `about()`**：两张环境卡片——`建议使用环境`（静态推荐配置：系统/浏览器/网络/权限/屏幕）+ `制作环境（本机运行环境）`（运行时探测 OS/设备/运行环境/CPU/内存/GPU/屏幕）。版本号展示 `v1.6.0`，署名为「科技推广中心」。

## 4. 关键算法
- **ZIP store 写入**：见 1.2，纯字节拼接，不含压缩，确保奥维可读。
- **筛选并集/交集**：`passFilter` 中各组空=不限制，组内 `includes`（并集），跨组 AND（交集）。
- **自动定位**：应用筛选后 `fitToShown()` 用图层 bounds `pad(0.12)` 自适应；选管理所即定位到该所点位中心范围。
- **默认质心**：怀柔水库所 7 点均值 (40.30876, 116.61107)，硬编码为 `DEFAULT_CENTER`。
- **图源切换**：`setLayer("img"|"vec")` 设置 `layerType` 并 `addBasemap()`；`addBasemap()` 先移除四图层再按 `basemapOn` 与 `layerType` 添加 vec+cva 或 img+cia；`updateLayerBtn()` 同步顶栏按钮文字。
- **测距 `haversine`**：`R=6371000`，`toRad=x*π/180`，`a=sin²(Δlat/2)+cos(lat1)cos(lat2)sin²(Δlon/2)`，`d=2R·asin(√a)`；累计各相邻顶点距离；≥1000m 显示 km 否则 m。
- **周边筛选**：`openNearby()` 选中心（我的位置/地图中心/某建筑物/地图点选）+ 半径(200–10000m)，写入 `nearbyCenter/nearbyRadius`；`passFilter` 增加 `haversine(nearbyCenter,{lat,lon})<=nearbyRadius` 约束（与现有筛选取交集），并绘制 `L.circle` 范围圈。

## 7. 错误处理与降级
| 场景 | 处理 |
|------|------|
| 无 Service Worker（非 http） | 不注册，仍可运行（PWA 离线缓存失效但功能正常） |
| APK 中 fetch 失败 | 回退 `window.__DATA__`（data.js） |
| 定位不支持/被拒（PWA） | toast 提示开启站点定位权限，不崩溃 |
| 定位被拒（APK WebView） | 经 `AndroidBridge.openLocationSettings()` 跳转系统定位设置 |
| 导航无我的位置 | 仅打开目标点位置（高德 marker URI） |
| ZIP 解压环境不支持 deflate | 提示改用 KML 文本导入 |
| localStorage 写入失败 | 静默降级为首次默认（不阻塞） |
| 导入格式不支持 | 抛出明确错误并 toast |
| 照片过大致 IndexedDB 膨胀 | 用户可控（导出备份清理） |
| 列表定位坐标非法（NaN） | 明确 toast「该建筑物缺少有效坐标」，不再静默失败 |
| 弹窗无法关闭 | × / 点遮罩 / 返回键(Esc) 三种方式；原生 onBackPressed 委托 APP.back() 逐级关闭 |
| 安卓选文件/导出无反应 | WebView 经 onShowFileChooser 接入 SAF；导出经 exportFile 唤起 SAF 保存选择器 |
| 大文件导入超 3GB 中断 | `IMPORT_CP` 检查点 + `importCpResumePrompt` 续传；`importCpTouch/End` 收尾，不从头重来 |
| 无 WiFi 导入/导出大文件 | `netInfo()` 判定非 WiFi → `confirmLargeTransfer` 弹流量警告，用户确认才继续 |
| 导入内容重复（同名不同内容/同内容不同名） | `shaHexOfB64`/`IO.sha256Hex` 算内容指纹，与 `importedSources` 比对，弹**覆盖/跳过** |
| 网盘未配凭证 | `netdiskImport/Export` 仅 toast 引导配置，不静默失败、不发起空请求 |
| 手机互传需同 WiFi 真机 | `ServerSocket` 局域网服务已编译；客户端拉取需在真机 + 同一 WiFi 下实跑验证 |

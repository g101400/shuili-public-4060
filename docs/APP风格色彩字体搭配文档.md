# 水利工程一张图 · APP 风格 / 色彩 / 字体搭配文档

> 版本：v1.99 ｜ 适用：shuili（水利）/ shipin（视频设备）/ gujian（古建）三套 APP
> 说明：三套 APP 共用同一套设计变量，仅语义色（行业强调色）与少量文案不同。改主题只需调 `css/style.css` 的 `:root` 变量，无需动逻辑代码。

## 1. 设计原则
- 浅蓝主调，界面不过深；浅色文字（白/浅蓝）保证在蓝底上的可读性。
- 全 APP 统一通过 CSS 变量驱动，菜单 / 抽屉 / 弹窗 / 按钮 / 卡片风格一致。
- 强调色用于主操作（导出、确定、分享等），危险色仅用于删除等破坏性操作。

## 2. 色彩变量（:root，2026-08-17 再调浅一档）
| 变量 | 值 | 用途 |
|------|------|------|
| --bg | `#1a456f` | 页面/地图外区底色 |
| --panel | `#3f7fb8` | 菜单/抽屉/弹窗主面板背景 |
| --panel2 | `#4f93c9` | 次面板（输入框、次级按钮、图标底） |
| --line | `#6aa6d8` | 分隔线 / 边框 |
| --txt | `#f2f9fe` | 主文字（浅色） |
| --muted | `#d2e6f5` | 次要文字 |
| --accent | `#6cc1ff` | 主强调色（主按钮、图标高亮） |
| --accent2 | `#54e3b4` | 次强调色（确认/成功按钮） |
| --danger | `#ff5d6c` | 危险操作（删除） |
| --warn | `#ffb454` | 警告 |
| --shadow | `0 6px 24px rgba(0,0,0,.35)` | 浮层阴影 |

> 历史：v1.9.5 整体调浅为浅蓝；v1.9.6 `--panel` #1d4a7a→#2a6098；v1.9.7 再调浅 `--panel` #2a6098→#3f7fb8、`--panel2` #3370a8→#4f93c9、`--bg` #163a63→#1a456f，缓解「菜单背景偏深」。

## 3. 字体
- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`
- 正文 14px；标题 16px（弹窗头）/ 按钮 14px 600；小字提示 12–13px。
- 中文优先「PingFang SC / 微软雅黑」，保证 Windows/Android/iOS 一致观感。

## 5. 修改指引
1. 改整体深浅 → 仅调 `:root` 的 `--bg/--panel/--panel2/--line`。
2. 改品牌强调色 → 调 `--accent/--accent2`。
3. 渐变里残留的硬编码 `#2a6098` 为兼容旧底，随 --panel 同步提亮，可一并替换。
4. 改完在三套 APP 的 `css/style.css` 同步相同变量，保持家族一致。

## 6. 2026-08-20 增补：弹窗与标记配色

| 元素 | 背景 | 文字 | 说明 |
|------|------|------|------|
| Leaflet 信息弹窗 | `--panel`（深蓝） | `--txt` | 覆盖 Leaflet 默认白底；`--muted` 浅蓝在白底上不可读，故整体改深色主题 |

| 标记调色板 `.mc-swat` | 各色 | 选中 `--accent` 描边 | 8 色圆点 |
| 形状选择 `.mc-shp` | `--panel2` | 图标 | 水滴/方块/圆/三角 |

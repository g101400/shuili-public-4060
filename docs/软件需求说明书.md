## 1. 引言

### 1.1 目的
本文档定义"水利工程一张图"软件的功能需求、数据需求与非功能需求，作为后续概要设计、详细设计、开发、测试与验收的依据。

### 1.2 范围
本软件面向水利工程管理单位，将一线人员用**奥维互动地图（OvitalMap）**采集的水工建筑物坐标、工程参数与照片，转换为可在**手机与电脑跨端查看、检索、编辑、共享**的一张图。提供两种交付形态：
- **PWA（渐进式 Web 应用）**：现代浏览器 / 安卓 Chrome「添加到主屏幕」即成为 App；
- **Android APK**：基于 WebView 的原生安装包，数据离线内嵌。

### 1.3 术语
| 术语 | 说明 |
|------|------|
| OVKMZ / KMZ | 奥维 / Google Earth 压缩包，内含 `doc.kml` + 照片附件 |
| 天地图（Tianditu） | 国家地理信息公共服务平台，提供 WMTS 矢量/注记底图 |
| 管理所 | 数据字段 `office`，如「怀柔水库所」「温泉所」 |
| 管理站 / 渠道段 | 数据字段 `station`，文件夹路径第 3 级「--」之前 |
| 建筑物类型 | 数据字段 `btype`，文件夹路径第 3 级「--」之后，如「节制闸」「跌水」 |
| 我的改动 | 用户在本地对基础数据所做的增/删/改，以增量 delta 存于 IndexedDB |
| PWA | Progressive Web App，可安装、可离线、免应用商店 |
| WebView | Android 中承载网页的组件，本应用以 file:// 加载本地 H5 |

## 2. 业务背景与目标
- **现状痛点**：同事用奥维采集工程数据，照片与参数以奥维附件形式存储，同步给他人不便；领导要求把工程数据展示在「一张图」，手机端与电脑端都能看。
- **目标**：
  1. 把奥维数据转成可共享、跨端的水利工程一张图；
  2. 支持按管理所 / 建筑物类型检索并自动定位；
  3. 支持移动端现场增删改建筑物与上传多张照片；
  4. 支持以奥维可识别的 ovkmz/kmz 格式导入导出（含照片）；
  5. 默认无底图、省流量、可离线使用；首次仅显示本单位（怀柔水库所）点位。

## 5. 功能需求

### FR1 地图浏览与默认视图
- 打开后加载地图，默认中心为**怀柔水库所**点位质心（约 40.30876, 116.61107），缩放 12。
- 默认**不加载天地图底图**，仅显示点位标记，省流量。
- 点击标记弹出详情（名称、管理所/管理站/类型标签、工程参数表、照片缩略图、编辑/删除按钮）。

### FR2 默认状态持久化
- 关闭并重新打开时，恢复上次的筛选条件、底图开关状态、地图视图（中心+缩放）。
- 首次打开（无历史状态）：默认 `管理所 = 怀柔水库所`、底图关闭、地图定位到怀柔水库所范围。
- 实现：UI 偏好存于 `localStorage`（key `ui_state`），失败则静默降级为首次默认。

### FR3 底图开关与图源切换
- 顶栏 🗺/🚫 按钮切换天地图底图的显示/隐藏；关闭时只显示点位，开启需联网（WMTS，`tk=` 浏览器端令牌）。
- **图源切换**：顶栏「矢量/影像」按钮或菜单「图源切换」可在**矢量地图（vec 底图 + cva 注记）**与**影像地图（img 底图 + cia 注记）**之间切换；图源选择随 UI 偏好持久化。

### FR4 搜索
- 顶栏输入框，按建筑物**名称**实时过滤（不区分大小写，包含匹配）。

### FR5 筛选（多选 + 自动定位）
- 菜单 → 筛选，提供两组多选 chips：
  - **建筑物类型**（如 节制闸、跌水）
  - **管理所**（如 温泉所、怀柔水库所）
- 规则：各组为空表示「不限制」；组内多选为**并集**；类型与管理所为**交集**（同时限定时，显示同时满足两者的点位）。
- 点击「应用」后：地图自动 `fitBounds` 到当前筛选结果的范围（选管理所即定位到其点位中心范围）；点击「重置」清空筛选。
- 参考 CSV 文件夹层级生成筛选项（真实值见附录 A）。

### FR6 详情与照片查看
- 弹窗展示工程参数（前 12 项）与照片缩略图；点击缩略图打开大图灯箱（lightbox），显示说明文字。

### FR7 添加建筑物（v2.01 起：坐标优先两步式）
- 菜单 → 添加，先进入「第 1 步：获取坐标」向导：支持①我的位置（geolocation）②地图点选（关闭弹窗后地图点击取坐标）③搜索已有建筑物（按名取其坐标）④手填经纬度；可「稍后填坐标」跳过（坐标为空仍可继续）。
- 坐标获取后进入「第 2 步：填写信息」，表单字段：名称（必填）、建筑物类型、管理所、管理站/渠道段、经度、纬度（由第 1 步预填，可重选）、工程参数（多行 `字段: 值`）、照片（可多张：正面/背面/侧面/全景/细部…）。坐标优先可从源头杜绝经纬度漏填导致标记落不了图。
- 保存后写入「我的改动」（added）。

### FR8 编辑 / 删除
- 点开标记 → 编辑 / 删除。
- 编辑：复用添加表单，预填原值；保存后若原为基础数据则记入 `updated`，若为已添加数据则直接更新。
- 删除：确认后若为基础数据记入 `deleted`，若为已添加数据从 `added` 移除。
- 注：删除/编辑仅作用于本地「我的改动」delta，基础数据只读、可重置恢复。

### FR9 导入
- 菜单 → 导入，支持：
  - `ovkmz` / `kmz`：解压读取 `doc.kml` + 照片，还原点位与照片（纯前端自研 ZIP，store/deflate-raw 均支持）；
  - `kml`：解析 Placemark 与 SimpleData；
  - `csv`：解析 文件夹/名称/经度/纬度/Comment 字段，还原 office/station/btype 与参数。
- 导入按 `id` 匹配：已存在则更新，否则新增。

### FR10 导出
- 菜单 → 导出，可选范围（全部 / 当前筛选）与格式：
  - `ovkmz` / `kmz`：zip 包（doc.kml + 照片），**奥维可识别导入**；
  - `kml`：通用 KML（不含照片）；
  - `csv`：属性表（含文件夹层级与 Comment）。
- 文件名默认「水利工程基础信息」。

### FR11 我的改动备份 / 恢复
- 菜单 → 导出/导入我的改动：把本地 delta 导出为 JSON 文件，或导入他人/他机 JSON，实现备份与迁移。

### FR12 统计概览
- 菜单 → 统计：显示建筑物总数、我的改动数，以及「按管理所」「按建筑物类型」的分布计数。

### FR13 定位我的位置
- 菜单 → 定位我的位置：调用浏览器/系统定位，成功后地图上标记「我的位置」（绿点）；记录坐标供导航作为起点。
- **未授权自动跳转设置**：若定位被拒绝或定位服务未开启，PWA 提示在浏览器站点设置中允许定位；APK（WebView）通过 JS Bridge 直接拉起系统「定位设置」页，用户授权后即可重定位。
- Android 已声明 `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` 权限，并配置 WebView 地理权限与运行时申请。

### FR14 重置
- 菜单 → 重置：清空全部「我的改动」，恢复到基础数据（407 条）。

### FR15 帮助
- 菜单 → 帮助：内置操作指引（浏览/搜索/筛选/添加/编辑/导入导出/底图/离线/安卓）。

### FR16 关于
- 菜单 → 关于：软件简介与**作者署名：科技推广中心**。

### FR17 标记样式（倒立蓝色水滴）
- 建筑物点位标记采用**倒立蓝色水滴状**图标（尖端朝上、圆鼓覆盖点位），中心含**小白点**；图标为内联 SVG（divIcon），缩放清晰、PWA 与 APK 通用。

### FR18 选定建筑物导航
- 点开建筑物弹窗 → 导航：优先使用「我的位置」作为起点，拼接高德地图 URI（含 `coordinate=wgs84` 自动坐标转换），跳转第三方导航软件（高德等），由用户选择导航 App；无我的位置时仅打开目标点位置。
- APK 通过 JS Bridge 唤起应用选择器；浏览器新标签页打开。

### FR19 测距
- 菜单 → 测距：进入测量模式后，依次点击地图或建筑物即可添加测量点；实时绘制折线并显示累计距离（≥1000m 显示 km，否则 m，haversine 公式）；支持清除与退出。

### FR20 周边建筑物搜索
- 菜单 → 周边搜索：选择中心（我的位置 / 当前地图中心 / 指定建筑物 / 地图点选）与半径（200–10000m），高亮并显示范围内建筑物、在地图画范围圈；与现有筛选为交集叠加。

### FR21 天地图 Token 环境化配置
- `index.html` 顶部 `window.__CONFIG__` 配置块集中管理天地图令牌：浏览器端 `TIANDITU_TOKEN`（前端底图加载）与服务器端 `TIANDITU_SERVER_TOKEN`（瓦片下载脚本）；不同部署环境仅需替换该块，无需改动业务代码。

### FR22 导出 / 导入文件夹选择器（Android）
- 安卓 APK 的导出 / 导入须经**系统文件夹选择器（SAF）**：导出弹出「保存位置」选择器（默认手机文档，可自定义路径与文件名）；导入弹出文件选择器（默认手机文档，可浏览任意目录、可多选）。
- 网页 / PWA 端导出走浏览器默认下载，导入为系统文件对话框（受浏览器能力限制，无"目录"概念）。
- 同一套 `<input type=file>` 与 JS Bridge，覆盖"添加照片""导入我的改动""导入 ovkmz/kmz/csv"等全部选文件场景。

### FR23 关于页：建议使用环境 + 制作环境
- 菜单 → 关于：除版本与"制作：科技推广中心"外，增加两张环境卡片：
  - **建议使用环境**：运行本应用所推荐的系统 / 浏览器 / 网络 / 权限 / 屏幕配置（静态指导）。
  - **制作环境（本机运行环境）**：当前设备实际的操作系统、设备型号、运行环境、CPU 核数、内存、GPU、屏幕分辨率与 DPR（运行时探测）。

### FR24 弹窗与界面退出（防"进去了退不出"）
- 任意弹窗均可通过三种方式关闭：**点右上角 ×**、**点弹窗外灰色遮罩**、**按手机返回键 / 电脑 Esc**。
- 安卓物理返回键优先级：关闭弹窗 > 关闭抽屉菜单 > 退出测距 > 关闭列表栏 > 系统默认返回。
- 测距可由：点浮条"退出"、**再次点击菜单"测距"**、按返回键 / Esc 三种方式退出。

### FR25 异形屏与安全区 / 遮挡适配
- 全量采用 `env(safe-area-inset-*)` 适配刘海屏与底部手势条（顶栏、列表栏、测距浮条、提示、照片大图关闭、选点提示）。
- 窄屏（<380px）顶栏标题自动隐藏、图标按钮缩排，避免与菜单/搜索框重叠遮挡。
- 标记图标与弹窗层级（z-index）明确，避免菜单与地图内容互相遮挡。

### FR26 列表定位异常保护
- 列表点"定位"时，若记录缺少有效坐标（如 KMZ 导入所得的 NaN 坐标），不再静默失败，改为明确提示"该建筑物缺少有效坐标，无法定位"，并始终收起列表。

### FR27 用户使用文档
- 随包提供《用户使用文档》（快速入门 + 功能逐项说明 + FAQ + 回退），与本文档及设计文档保持同步。

### FR28 主菜单恢复（三击）
- 当建筑物列表打开或某弹窗/列表遮挡导致主菜单（左侧抽屉）一时找不到时，用户可在**地图任意处快速连点三下**，系统先关闭卡住的弹窗/列表、再打开主菜单；顶部 ≡ 菜单按钮始终保持可点，作为备用入口。测距/选点模式下不触发三击，避免误操。

### FR29 列表项快速定位
- 建筑物列表每项的名称后显示徽标：基础数据项显示蓝色「快速定位 →」，用户新增项显示「新增」；点击整行或徽标即飞到该建筑物地图位置并收起列表。

### FR30 获取经纬度
- 新增「获取经纬度」功能：支持三种取坐标方式——① 我的位置（geolocation，未授权跳转系统设置）；② 地图点选（关闭弹窗后在地图点选，坐标回填）；③ 搜索建筑物（按名称过滤并列出其坐标、飞到该点）。坐标以 WGS84 十进制展示，支持一键复制「纬度, 经度」。

### FR31 弹窗关闭图标醒目化
- 所有弹窗与抽屉的关闭 × 改为圆形高亮按钮（点击变红），更易辨识与点按；列表栏、抽屉均带独立关闭 ×；结合遮罩点关、返回键/Esc，任意层级均可退出，杜绝"找不到主菜单"。

### FR32 批量导入照片
- 新增「批量导入照片」：支持三种来源——指定手机文件夹（Android SAF 文件夹选择器）、zip 压缩包（含照片）、多文件选择（网页端回退）。
- 导入后按**照片文件名（去扩展名、规范化小写并去除空格/下划线/连字符/括号）**匹配建筑物名称：先精确匹配、再包含匹配；匹配成功则把该照片写入对应建筑物的照片列表（新增或追加），匹配失败则列出未匹配文件供人工处理。
- 仅 Android APK 支持文件夹/zip；网页/PWA 端支持多文件选择，不提供"目录"概念。

### FR33 批量导入建筑物信息
- 新增「批量导入建筑物」：支持指定手机文件夹 / zip 压缩包 / 多文件（网页端回退），文件类型涵盖 csv / tsv / txt / kml / gpx / json / xlsx 等电子表格或交换格式。
- xlsx 在 Android 原生层 best-effort 转为 csv（解析 `sharedStrings.xml` + `worksheets/sheet*.xml`）后回传前端文本；其余格式在前端按扩展名分流解析。
- 导入后按 `id` 匹配：已存在则更新、否则新增；含经纬度按坐标定位，无经纬度按名称定位。

### FR34 批量导出照片
- 新增「导出照片」：支持两种输出方式——① zip 压缩包（照片以 `建筑物名称_序号.扩展名` 命名打包下载）；② 导出到指定手机文件夹（Android SAF 文档树写入，含子目录层级）。
- 可指定范围：全部建筑物 / 当前筛选结果。网页/PWA 端仅支持 zip 压缩包下载。

### FR35 批量导出建筑物信息
- 增强「导出」：支持**多选部分建筑物**（复选框 + 全选/全不选 + 计数），而非只能全部导出。
- 导出格式新增**潮河格式（CSV 兼容）**：字段为 `名称,管理所,管理站,建筑物类型,经度,纬度,说明`（工程参数用 `;` 连接）；同时保留通用 CSV（字段 `文件夹,名称,经度,纬度,Comment`）。
- 导出位置可选 `saf`（单文件保存选择器）或 `folder`（指定文件夹/文档树），folder 模式为 Android APK 专属。

### FR36 照片匹配优化：多候选人工确认（v1.7.0）
- 导入照片按文件名（去扩展名、忽略末尾数字）匹配建筑物时，若一张照片匹配到**多个**建筑物（如 `峰山口.jpg` 同时匹配"峰山口测流桥"与"峰山口防洪闸"），**不得自动落库**，弹出勾选框让用户选择保存目标（**可多选**）；仅匹配 1 个时直接保存；无匹配列入未匹配清单。

### FR37 照片匹配优化：忽略末尾数字（v1.7.0）
- 照片名尾部数字在匹配时忽略：`峰山口1.jpg` / `峰山口2.jpg` 的匹配键均归一为 `峰山口`，与对应建筑物匹配规则与 FR36 一致（精确/包含匹配）。

### FR38 照片导出按管理所分组 + 序号（v1.7.0 收尾）
- 导出照片时，含多张照片的建筑物在文件名后加**序号**（`建筑物名称_1.jpg` …）；导出结果**按管理所分文件夹**（rel 路径 `管理所/建筑物名称_序号.扩展名`），zip 与 SAF 文档树均支持嵌套路径（v1.6.0 仅完成序号命名，分文件夹于 v1.7.0 收尾）。

### FR39 超大文件导入/导出（ovkmz/kmz >3GB）（v1.8.0）
- 导入/导出 kmz/ovkmz 因含大量照片可能超过 3GB；提供**超大文件模式**：导入支持**断点续传**（内存检查点 `IMPORT_CP`，中断后可继续，不从头重来）、无 WiFi 时弹窗提示"将消耗大量流量"（`confirmLargeTransfer` + `netInfo` 读 `navigator.connection`）；导出侧提示同效。

### FR40 超大文件导入/导出（照片/zip >3GB）（v1.8.0）
- 批量导入/导出照片或 zip 包同样按超大文件模式处理：导入断点续传、中断续传；无 WiFi 流量提示；与 FR39 共用同一套 `netInfo` / `confirmLargeTransfer` / `importCp*` 机制。

### FR41 内容去重提示（按内容而非文件名）（v1.8.0）
- 导入 kmz/照片时计算内容指纹：`sha256Hex()`（优先 `crypto.subtle.digest` SHA-256，不支持则降级 CRC32）；若内容与已导入源**完全相同**（非文件名相同），弹窗提示**覆盖 / 跳过**，避免重复导入占用空间。

### FR42 网盘导入导出脚手架（百度/夸克）（v1.8.0）
- 新增「传输与共享 → 网盘导入导出」：可选百度网盘 / 夸克网盘，支持 kmz 与照片的导入/导出。
- 实现为**凭证门控脚手架**：原生 `AndroidBridge.netdiskImport(provider,kind)` / `netdiskExport(provider,fmt)` 调用；未配置 AppKey/Token 时 toast 引导用户配置，不静默失败。真机需用户提供网盘凭证后实跑激活。

### FR43 手机互传（服务端 / 客户端 P2P）（v1.8.0）
- 新增「传输与共享 → 手机互传」：两台同装本 App 的手机，一台开**服务端**（原生 `ServerSocket` 起局域网 HTTP 服务，分享 kmz/照片），另一台开**客户端**从服务端下载 kmz 或照片。
- 服务端经 `pickLanShare()` 选文件 → `startLanServerNow(port)` 后台 `ServerSocket`；客户端 `lanClientMenu()` 填服务端地址 `http://addr:port/` 拉取并导入。需在**同一 WiFi** 下真机验证。

### FR44 菜单重排与整体优化（v1.8.0）
- 在不删除任何已有功能/菜单的前提下，智能优化菜单顺序与分组：新增「**传输与共享**」分组（含 网盘导入导出、手机互传），将大文件/传输能力聚拢；整体 UI/交互梳理（与既有"地图与位置 / 数据管理 / 信息与帮助"分组共存）。

> **遗留待办（Backlog）**：FR35 中的"导出建筑物表格**可选列**"（用户勾选字段列 + 前置筛选）在 v1.7.0/v1.8.0 尚未实现，状态仍为 `○待做`，列入《软件变更文档》§6 Backlog，待后续版本补齐。

## 9. 验收标准
1. 打开应用，首次默认显示怀柔水库所点位、无底图；再次打开恢复上次状态。
2. 筛选「节制闸」→ 仅显示节制闸；同时选「温泉所」→ 自动定位到温泉所范围。
3. 可成功添加/编辑/删除建筑物并上传多张照片，刷新后仍保留（本地）。
4. 导出 ovkmz → 用奥维「导入」可正确还原点位与照片（已通过 Python zipfile 独立校验）。
5. 导入 ovkmz/kmz/kml/csv 可还原点位与照片。
6. 编译出的 APK 安装后，图标为蓝色水滴「科推」，首屏功能与 PWA 一致。
7. 关于页作者为「科技推广中心」。

## 2026-08-20 增量需求（v1.99）

- **FR-40 标记自定义**：每个建筑物可设置标记颜色（8 色）与形状（水滴/方块/圆/三角）；地图左下角图例列出自定义样式建筑物（名称+色样），便于分类区分。
- **FR-41 导入同名提示**：导入 kmz/ovkmz/表格时，与现有记录名称完全相同的建筑物须弹窗三选：覆盖同名 / 跳过同名 / 取消；同文件重复导入按内容指纹提示（原有 FR-内容去重保留）。
- **FR-42 可读性**：所有弹窗（含 Leaflet 信息弹窗）文字与背景须保持足够对比度（深底浅字、参数键亮蓝加粗），不允许浅字白底。
- **FR-43 四端功能对照单**：App 帮助菜单提供「四端功能对照单」子项，展示四平台功能差异与各版本差异（数据由 `platform_matrix.js` 提供）。
- **FR-44 底图入口去重**：底图选择仅保留一个入口（顶栏「矢量」/菜单「图源切换」），删除重复的图标按钮与「底图开关」菜单项。
- **FR-45 统信交付形态**：统信 UOS 只交付 deb 安装包，不再生成绿色版 tar.gz。

- **FR-46 地图控件**：地图页提供放大（＋）/缩小（－）/收藏当前位置（★）/返回收藏位置（⤺）按钮；收藏位置本地持久化（跨会话有效）。
- **FR-47 zip 导入健壮性**：zip 照片导入必须支持任意第三方压缩包（含目录条目 / data descriptor / 多层目录），解压有超时兜底，不得出现「一直显示正在处理」卡死；导入 / 导出均支持多层目录结构。
- **FR-48 管理所名称规范化**：导入 / 导出统一将「XX管理所」规范为「XX所」（潮河管理所 / 潮河总干渠管理所 → 潮河所）；查询 / 筛选忽略「管理」两字（史山所 = 史山管理所）；站是所的下一级单位，不合并。

- **FR-50 四端对照单版本化**：四端功能对照单随版本更新，记录每个版本的平台差异点（v2.0 起在 App 内菜单可见）。
